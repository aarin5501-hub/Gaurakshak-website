# Gaurakshak

Bovine health monitoring and early mastitis risk-screening prototype for farmers and veterinary teams.

## Features
- Farm overview and herd risk summary
- Animal profile and health monitoring
- Wearable-tag parameters
- Milk test-card workflow for SCC, LDH and NAGase
- Health history and trend views
- Nutrition and feed guidance
- Hygiene and best practices
- Mastitis warning signs
- Animal and farm records
- English, Hindi and Marathi interface
- Farmer support, alerts and veterinary escalation guidance

## Monitoring parameters
Body temperature, heart rate, activity, rumination, feeding behaviour, resting/lying time, milk yield, udder condition, ambient temperature, relative humidity, milking frequency, previous mastitis, previous SCC, treatment/antibiotic/vaccination history and animal location.

## Important
This is a demonstration prototype. Displayed readings and risk outputs are illustrative and require field validation and veterinary assessment before real-world use. Reference information is for educational and screening support and is not a standalone diagnosis.

## Run locally
Open `index.html` in a modern browser.

## Deployment
The project is a static HTML/CSS/JavaScript website and can be deployed through a Git repository connected to Vercel.
